## 🔄 2. The 3-Step Precision Engineering Workflow

For every major feature or project:

### Step 1: Deconstruct & Delegate
* Break the requirement into:
  * **Interactive Tasks (Antigravity)**: UI/UX, core API routes, state management, security boundaries.
  * **Asynchronous Cloud Tasks (Google Jules)**: Comprehensive test suites, background worker scripts, type definitions, and automated cloud validation.

### Step 2: Parallel Deep Execution
* **Antigravity** writes code with deep creative precision:
  * No lazy placeholders or minimal viable code.
  * Rich micro-interactions, robust error boundaries, and pristine ergonomics.
* **Google Jules** executes the cloud tasks asynchronously via `google_jules` skill.

### Step 3: Peer Audit & Synthesis
* Antigravity reviews Jules’s PR diffs or cloud artifacts.
* Verifies zero security regressions and zero concurrency flaws.
* Combines everything into a unified, flawless delivery.
