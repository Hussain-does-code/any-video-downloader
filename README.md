# 🚀 Apex Universal Video Downloader

A high-performance universal video and audio downloader powered by Node.js, Express, yt-dlp, and FFmpeg.

## Features
- 🎬 High-speed video downloading across popular platforms
- 🎵 Audio extraction (MP3 / AAC / M4A)
- ⚡ 16-connection parallel chunk streaming
- 📊 Real-time download progress tracking
- 🛡️ Built-in SSRF protection and path traversal defense
- 🧹 Automatic storage cleanup and garbage collection
